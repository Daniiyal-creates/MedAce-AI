### MDCAT
- Definition：Medical and Dental College Admission Test — Pakistan's high-stakes pre-medical entrance exam that MedAce AI prepares students for; all MCQs and the interface mirror the real exam language (English), while explanations can be provided in Urdu when needed.

### FSc 12th-grade Biology
- Definition：The Federal Board of Intermediate and Secondary Education (Punjab) Biology textbook curriculum for 12th grade, which serves as the authoritative source material for MedAce AI's RAG knowledge base; questions generated by the system are grounded strictly in these chapters.
- Aliases：FSc Biology、Punjab textbook board Biology

### SLO code
- Definition：Student Learning Outcome code (e.g., `[B-12-R-24]`) embedded in each textbook chapter that marks a specific learning objective; used as natural topic/concept boundaries for chunking textbook content and for generating syllabus-aligned MCQs per SLO.
- Aliases：SLO、Student Learning Outcome code

### RAG pipeline
- Definition：Retrieval-Augmented Generation workflow that indexes FSc Biology textbook chapters into Supabase pgvector (build-time: clean → chunk by SLO/headings → embed with text-embedding-004 → upload) and, at query time, retrieves top-K relevant chunks via cosine similarity before prompting Gemini to generate MCQs grounded in the retrieved context.
- Aliases：RAG、retrieval-augmented generation

### MCQ player
- Definition：The practice session page (`/practice/[session]`) where students answer multiple-choice questions generated from the RAG pipeline, with features including a timer, option selection, toggle between English and Urdu explanations, and post-answer feedback.
- Aliases：MCQ session、quiz player

### weak spots
- Definition：Topics where a student repeatedly answers incorrectly, tracked per user in the `weak_topics` table; the app surfaces these on the dashboard and uses them to adapt future practice sessions toward areas needing improvement.
- Aliases：weak topics、weak spot tracking

### study plan
- Definition：A 7-day adaptive schedule generated by Gemini based on a student's weak spots and progress, displayed on `/study-plan`; includes today's tasks and an AI-generated rationale explaining why those topics were selected.
- Aliases：adaptive study plan、weekly study plan

### Dark Medical Premium
- Definition：The chosen design theme for MedAce AI's UI — a dark-themed, premium-feeling aesthetic applied across all pages using Tailwind CSS v4 tokens defined in `globals.css`.
- Aliases：dark theme、medical premium theme
