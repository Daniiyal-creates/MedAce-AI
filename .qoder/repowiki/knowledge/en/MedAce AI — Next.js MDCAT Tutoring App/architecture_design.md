The app follows the standard Next.js 15 App Router layout: `src/app` holds route groups `(auth)` for login/signup and `(dashboard)` for protected pages (quiz, history, profile, study-plan), each with its own `layout.tsx` and page components. Server-side API endpoints live under `src/app/api/` as per-route handlers (`quiz/generate`, `quiz/history`, `quiz/submit`, `quiz/weak-topics`, `study-plan`) that call domain libraries in `src/lib/`. The `lib` layer is split by concern: `supabase/` (client, server, middleware), `gemini/` (LLM client + prompts), `drizzle/` (schema), `hooks/` (React hooks), plus shared `constants.ts` and `utils.ts`. UI is organized under `src/components/` into feature folders (`auth`, `dashboard`, `quiz`, `layout`, `ui`) with a shared `ui/` primitive library. Global state and cross-cutting concerns are provided via React context providers in `src/providers/` (`AuthProvider` wrapping Supabase auth, `QueryProvider` wrapping TanStack Query). A Next.js `middleware.ts` re-exports `updateSession` from `@/lib/supabase/middleware` to refresh sessions on every request. The root `layout.tsx` sets `lang="ur" dir="rtl"` for Urdu RTL rendering and wraps all children in both providers. Database schema and migrations are managed through Drizzle Kit configured in `drizzle.config.ts` pointing at a Postgres instance via `DATABASE_URL`.
