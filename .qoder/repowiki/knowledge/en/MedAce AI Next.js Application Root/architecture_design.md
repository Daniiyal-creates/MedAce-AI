The project is a Next.js 15 App Router application (React 19, TypeScript 5) configured as a private monorepo root. `next.config.ts` enforces security headers (X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy origin-when-cross-origin, Permissions-Policy disabling camera/microphone/geolocation) via the `headers()` hook on all routes. `tsconfig.json` enables strict mode, `noEmit`, `isolatedModules`, bundler-style module resolution, and maps the `@/*` path alias to `./src/`. The stack layers are: UI (React + Tailwind CSS v4 with `clsx`/`tailwind-css` class merging), state/data fetching via TanStack Query v5, auth via Supabase Auth (Google OAuth), persistence via Drizzle ORM against Supabase PostgreSQL with pgvector for RAG embeddings, and AI generation/retrieval through Google Gemini (`gemini-2.0-flash` for MCQs and Urdu explanations, `text-embedding-004` for textbook chunk vectors). The RAG pipeline runs at build time via scripts under `rag/scripts/` (clean → chunk → embed → upload) and queries at runtime from API routes under `src/app/api/`.
