The repository is a single Next.js 15 project (no separate backend package) where the `src/app` directory provides both client pages and server-side API routes under `src/app/api/`. Client components consume data via TanStack Query against those API routes, which in turn call Supabase (PostgreSQL + pgvector) through Drizzle ORM and invoke Google Gemini for MCQ generation and Urdu explanations. The `rag/textbooks/*.txt` files feed a one-time ingestion script (`scripts/ingest-textbooks.ts`) that chunks content by SLO codes, embeds them with text-embedding-004, and stores vectors in Supabase for retrieval-augmented question generation. Security headers are centralized in `next.config.ts`, environment variables are templated in `.env.example`, and shared UI primitives live under `src/components/ui/` consumed by all feature pages.
