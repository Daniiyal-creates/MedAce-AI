This leaf module wires together the Next.js App Router entry points for the application shell. `src/app/layout.tsx` is the root layout: it declares global `Metadata` (title, description, OpenGraph, Twitter card, robots), loads the Inter font via `next/font/google`, imports the shared `Providers` context from `@/components/Providers`, and wraps every route in `<html>`/`<body>` with Tailwind utility classes plus a CSS variable (`--font-sans`) injected by the font loader. `src/app/page.tsx` is a `'use client'` React component that composes the marketing landing page from self-contained section components (`HeroSection`, `ProblemSection`, `FeaturesSection`, `HowItWorksSection`, `StatsSection`, `CTASection`) built on `framer-motion` for scroll-triggered animations and reuses shared UI primitives (`Button`, `Badge`, `Card`) from `@/components/ui`. `src/middleware.ts` implements a Next.js Edge middleware that currently allows all routes through but has a reserved `protectedRoutes` list (`/dashboard`, `/practice`, `/results`, `/study-plan`, `/profile`) with commented-out Supabase cookie-based auth redirect logic ready to be enabled. `src/app/globals.css` centralizes the app's design system: a Tailwind `@theme inline` block defines semantic color tokens (bg/surface/primary/accent/success/error/info), font variables, and glass/glow utilities; it also registers Google-hosted `Inter` and `Noto Nastaliq Urdu` `@font-face` sources and provides reusable animation keyframes and utility classes (gradient text, glass cards, shimmer, float, pulse-glow) consumed across the landing page sections.
