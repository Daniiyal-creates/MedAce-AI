After `npm install`, copy `.env.example` to `.env.local` and fill in `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `DATABASE_URL`, and `GEMINI_API_KEY`. Run database migrations with `npx drizzle-kit generate` then `npx drizzle-kit migrate`. Build the RAG index once via `npx tsx rag/scripts/clean.ts`, `chunk.ts`, `embed.ts`, `upload.ts`. Start dev server with `npm run dev`.
